شايني ستور - نسخة أولية مجانية
--------------------------------
هذه نسخة واجهة متجر تعمل محلياً بدون خادم وقاعدة بيانات.

المزايا:
- منتجات وتصنيفات كوزمتكس وعطور.
- إضافة منتجات من زر "إضافة منتج".
- سلة مشتريات.
- طلب من العميل مع الاسم والهاتف والعنوان والمحافظة.
- الدفع عند الاستلام أو زين كاش كخيار دفع.
- الشحن: البصرة 3000، أطراف البصرة 4000، باقي المحافظات 5000.
- مجاني فوق 80000 د.ع.
- نظام أولي للنقاط مذكور في الواجهة (10,000 = نقطة، 20 نقطة = هدية).

مهم:
- هذا إصدار واجهة/نموذج أولي، وليس نظاماً آمناً للإنتاج.
- خيار زين كاش هنا مجرد اختيار في الطلب؛ لا توجد بوابة دفع حقيقية أو ربط بحساب زين كاش.
- الطلبات محفوظة محلياً في متصفح الجهاز فقط.
- للنشر العام نحتاج استضافة وربط قاعدة بيانات ونظام إدارة للطلبات وربط دفع زين كاش الرسمي.
